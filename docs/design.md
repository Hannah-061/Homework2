# 畫面設計結果

> 這份文件記錄 `/design` 階段的成果，下一步做前端（`/frontend-design`）時照著用。
> 畫面「有什麼元素、按了會怎樣」的規格在 `docs/architecture.md` 第 7 節；這份文件只記**長什麼樣子**，以及設計過程中改過的決定。
> 兩份文件有出入時，以 `architecture.md` 的行為規格為準，以這份文件的外觀為準。

## 設計稿位置

- 畫布（13 個畫面，只有你能開）：https://claude.ai/artifact/STFCu9zrV9XvJUbDZJR7z6
- 畫布上的原始碼是 `.dc.html` 檔，放在畫布裡。**它們不在這個 repo 裡**，所以下面的色彩、字體與元件寫法已經整理在這份文件，做前端時不需要回頭解析畫布。
- 設計稿是靜態的，按鈕不會動；互動行為看 `architecture.md` 第 7 節。

## 風格方向

- 活潑、像遊戲機，手機優先，電腦版是同一套設計放大。
- 做法：粗黑邊框、硬邊陰影（像貼紙，沒有模糊）、圓角、像素風小裝飾。
- 只做**一套顏色**，沒有深色／淺色切換。**配色你說之後再選**，所以所有顏色都要集中在一個檔案（見下面的設計變數），之後換配色只改那裡。

## 設計變數

做前端時放在 `src/styles/theme.css`（`architecture.md` 第 11 節已規劃這個檔案）。

| 變數 | 值 | 用在哪裡 |
|---|---|---|
| `--ink` | `#1f1a3d` | 文字、邊框、陰影 |
| `--muted` | `#5a5580` | 次要文字（時間、說明） |
| `--paper` | `#fff4d1` | 畫面底色（帶點狀紋理） |
| `--white` | `#ffffff` | 他人訊息、卡片 |
| `--orange` | `#ffb27a` | 主要行動：進入、送出、離開、新訊息箭頭、Logo、標題陰影 |
| `--mint` | `#62e0a8` | 自己的訊息、在線標示、自己在名單中的那一列 |
| `--sun` | `#ffd447` | 頂部列、輔助按鈕（表情、圖片）、標籤 |
| `--violet` | `#8566ff` | 斷線橫幅 |
| `--sky` / `--sky-soft` | `#86d8ff` / `#e4f6ff` | 圖片底色／翻譯區塊底色 |
| `--night` / `--night-text` | `#2a2257` / `#ece8ff` | 輸入區底色／其上的文字、圖片放大的背景 |
| `--danger` / `--danger-soft` | `#b3123a` / `#fff0e2` | 錯誤文字與邊框／錯誤底色 |
| `--b` | `3px solid var(--ink)` | 標準邊框 |
| `--sh` | `4px 4px 0 var(--ink)` | 標準硬陰影（小元件用 2–3px） |

- 畫面底色的點狀紋理：`radial-gradient(rgba(31,26,61,.13) 1.5px, transparent 1.5px)`，間距 18px。
- **對比：** 橘、黃、薄荷這些亮色上的文字一律用 `--ink`，不用白色（白字會看不清楚）。次要文字用 `--muted`。
- **錯誤**不能只靠顏色：一定同時有警告圖示與文字。

## 字體

| 用途 | 字體 | 備註 |
|---|---|---|
| 全站中英文 | **Huninn**（Google Fonts，圓潤的繁體中文字體），備用 `Noto Sans TC`、系統字體 | 它只有一種字重，粗體是瀏覽器模擬的 |
| 像素風小裝飾 | **Press Start 2P**（Google Fonts） | 只用在「PLAYER 1」這類純裝飾的小標籤，字級 9px 左右，必須標 `aria-hidden`，**不能用來顯示重要資訊** |

- 本文字級：訊息 16px；代號輸入 20px（手機）／22px（電腦）；大標題 44px（手機）／64px（電腦）；時間、說明 12–14px。
- 載入方式：一個 Google Fonts `<link>`（`family=Huninn&family=Press+Start+2P&display=swap`）。

## 設計過程中改過的決定

這些是看畫布後你的修改，已反映在上面，**做前端時不要退回**：

| 項目 | 結果 |
|---|---|
| 手機頂部的在線人數 | 不要框，只顯示圓點加文字 |
| 粉紅色 | 一律改成淺橘色（`--orange`）。錯誤提示的淡粉紅底也改成淡橘，但文字與邊框維持紅色，讓錯誤仍然看得出來 |
| 新訊息提示 | 只有向下箭頭，**沒有文字**。數量放在按鈕的說明（`aria-label`）給螢幕閱讀器 |
| 收回自己的訊息 | 兩種方式都可以：點「⋯」選單，或長按（電腦版按住滑鼠）訊息。設計稿只畫得出「⋯」這條路 |

## 設計稿裡的示意內容

下面這些在設計稿裡只是示意，**做前端時要換成真的**：

- 範例對話、代號、時間：假資料。
- 連結預覽的縮圖與圖片訊息：用色塊與簡單圖案代替，真的要顯示使用者上傳／網站提供的圖片。
- 表情選單的表情：只畫了 21 個，真的選單用 `emoji-picker-element`（見 `architecture.md` 3.1），其分類頁籤與搜尋框的外觀照設計稿。
- 「PLAYER 1」小標籤：純裝飾。
- 設計稿裡的語言按鈕只有小地球；點開後的「中文／English」選單沒有畫，照 `architecture.md` 第 7 節「全站共通」做，外觀沿用選單元件。

## 設計稿還沒涵蓋、做前端時要補的

- 語言選單展開後的樣子。
- 圖片上傳中的進度與失敗重試（`architecture.md` 6.2）。
- 圖片錯誤提示（「圖片太大了」「只支援 JPG、PNG、GIF、WebP」）：沿用錯誤提示元件。
- 超過 450 字時的剩餘字數提示：已在 C2 畫出；超過 500 字不可再輸入。
- 長按訊息後出現的收回選項：沿用選單元件。
- 沒有任何訊息時的空狀態文字（「還沒有人說話，來打個招呼吧」）。
- 載入中的畫面（自動進入、讀取歷史訊息時）。

以上都沿用既有元件即可，不需要另外開新設計。若你想看某一項長什麼樣子再決定，告訴我，我補到畫布上。
