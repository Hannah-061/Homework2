# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. （其他你想到的）

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- （其他你想要的）

## 不需要的

- （其他你確定不要的）

## 後來新增的功能（開發途中追加）

### 提及（@）
- 輸入框打 `@` 會跳出**目前在線**的人的選單（可繼續打字篩選）；點在線名單裡的人，也會把 `@代號` 放進輸入框。
- 選單與名單都不含自己；已離開的人不能被提到。手動打、沒從選單選的 `@某某` 只是一般文字。
- 一則訊息最多提到 5 個人。
- 被提到的人：那一則訊息醒目、「新訊息」箭頭按鈕變醒目、在別的分頁時分頁標題顯示 (@)。沒有提示音、沒有瀏覽器通知。
- 被提到的人離開、別人用了同一個代號，新來的人不算被提到。

### 引用
- 每則訊息的「⋯」選單有「引用」（長按也能開出同一個選單）；輸入框上方出現「正在引用…」的小條，可取消。
- 送出後，訊息最上面有引用區（被引用的人、原文前幾十個字；圖片顯示「圖片」）。點引用區會捲到原訊息並閃一下；原訊息已被清掉時點了沒反應，仍看得到當時的摘要。
- 原訊息被收回：所有引用它的訊息，引用區改成「這則訊息已被收回」。原訊息被檢舉遮住：改成「這則訊息已被遮住」。
- 有人引用你的訊息，算「提到你」，畫面與分頁標題的提示跟被 `@` 一樣。
- 引用可以配文字或圖片一起送；只顯示一層，不會嵌套。
